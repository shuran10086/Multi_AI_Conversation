> 本文件只记录「从本机 DSH 安装包实测得到的事实」，供开发时查证。结论已汇入 `开工文档.md` 第 3 节；此处保留更细的原始依据与定位。

## 2. 导航 + 页面（最关键）
- slot `sidebar.panellist`（list, scope root）：左侧导航图标；注册项 `{ id, order?, label? }`。
- slot `main`（keyed, scope root）：中间主面板，按 `key` 切换；`key` 与导航 `id` 相同即绑定。
- 官方示例：`@deepseek-ai/dsh-client-ui-schedule/lib/client.js` 第 6793/6804 行（已提取为 `脚本文件/ref/schedule-client.js`）同时注册 `main` + `sidebar.panellist`，`PANEL_ID` 复用。
- 主动跳转：Client 服务 `ctx.layout.selectPanel(panelId)`。
- 结论：DSH **原生支持**插件注册左侧一级导航项，无需变通，不破坏现有功能。

## 3. Client 服务（`ctx.<key>`，实测 catalog）
- `slots`：register / registerFactory / inject
- `layout`：selectPanel / beginNavigation / toggleSidebar / openRightbar / closeRightbar
- `locale`：register / bind(ns)->t / setLocale / addLanguage
- `theme`：getTheme / setTheme / setFontSize / register / overrideTokens
- `sessions` / `uiWorkspace` / `workspaces`：会话与工作区（本插件暂不用）
- `timer`：timeout / interval / throttle / debounce

## 4. Host 服务（节选，实测 catalog）
- `credentials`：resolve/describe/set/unset/readRecord/... —— 存密钥用这个。
- `storage` / `storageDomain`：结构化存储 hub（可选的持久化后端）。
- `timer`：超时/节流。
- `web`：search/fetch（如需平台 fetch）。
- `agentLoop`/`agents`/`agentTeams`/`subagents`/`tools`/`systemPrompt` 等：与 Agent 运行相关，本插件自管对话、暂不依赖。
- Remote 暴露方式：Host 方法加 `@Remote(...)`，Client 经 `ctx.remote.<ns>.<method>()` 调用；流式用 `@Remote({ mode:'stream' })`，参考 schedule/terminalController。

## 5. 主题 token（实测，仅这些可用）
`--dsw-alias-bg-base / bg-layer-1 / bg-layer-2 / bg-overlay`
`--dsw-alias-border-l1 / border-l2`
`--dsw-alias-brand-primary`
`--dsw-alias-label-primary / label-secondary`
`--dsw-alias-state-error-primary / idle-primary / success-primary / warn-primary`
`--dsw-specific-sidebar-fill`
全部 `requiresLightAndDark`，由 DSH 切换值，插件引用变量即自动适配深浅色。

## 6. 插件清单与安装（实测）
- bundle = 带 `dsh.bundle.patch` 的 package；`cordis.patch.yml` 用 `- insert:` 插入行。
- UI 插件在 `package.json` 加 `dsh.client`：`{ platform:'web', immediately:true, inject:[...] }` 并导出 `./client`。
- 显示元数据/图标：`locale/*.json` 的 `meta.title/description` + 顶层 `icon`（相对路径 svg/png，≤256KiB）。
- Client 模块：`window.__ModuleLoader__.load({ id:<包名>, factory(require){ const React=require('react'); ... return { inject:['slots'], apply(ctx){...} }; } })`。React 来自浏览器模块表。
- Host 模块：`export function apply(ctx, config){}`（+ 可选 `inject`、`Config`）。
- 安装：`plugin_manager action=install_bundle target=<绝对路径>`；看返回 `application`/`warnings`，用 `Slots.listSubTree` 复核注册。

## 7. 硬性禁忌（practices.md 实测要点）
1. 不得 import 任何 `@deepseek-ai/dsh-client-ui-*`（inject 仅排序，非可用库）。自写控件、照抄样式、只共享 token。
2. 不得用 iframe 承载页面；页面必须是渲染进 slot 的 React 组件。
3. factory 无副作用；资源在 `apply` 内注册并返回清理（`ctx.effect`/`ctx.on`）。
4. 不替换 app 根、不写 `document.body`、不读他人 DOM。
5. 文字走 locale，颜色走 token，布局兼容缩放与深浅色。
6. 不新增会话事件类型（除非 envelope 带 `ignorable`）；插件数据放存储服务。

## 8. 提取工具用法（`脚本文件/asar_read.mjs`）
```

node asar_read.mjs <app.asar> grep <内容> [路径子串] # 全包搜内容
node asar_read.mjs <app.asar> cat  <内部路径>        # 打印到 stdout
node asar_read.mjs <app.asar> save <内部路径> <目标> # 存到本地文件（推荐，避免编码问题）
```
