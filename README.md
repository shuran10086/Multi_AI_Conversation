# 多AI对话 · Multi_AI_Conversation

一个 DeepSeek Harness（DSH）桌面端插件，让多个 AI 大模型在同一页面里轮流交流、协作讨论并自主迭代你的项目方案。

## ✨ 功能介绍

**多AI对话** 在 DeepSeek Harness 的左侧全局导航栏新增一个一级入口「多AI对话」，点击后进入插件独立页面。核心能力：

- **多模型管理**：在插件页面内配置 **最多 6 个** AI 大模型，每个模型可独立设置 **API 地址、密钥（Key）、模型名、人设/角色、温度** 等；与 DSH 自带的模型设置互不干扰。
- **双模式设计**：提供「**工作模式**」与「**游戏模式**」，两种模式各自独立配置、独立保存。
- **工作模式（核心）**：
  - 输入**项目目标**后，多个 AI **轮流自主交流讨论**，围绕目标头脑风暴、迭代完善方案；
  - 全程 AI **严格轮流**（一个讲完下一个才开始），每个 AI 都能看到其他 AI 的发言；
  - **超时自动跳过**：某个 AI 超时未回复就自动跳过轮到下一个，连续跳过多次后本轮不再叫它；
  - **用户随时插话**：支持「等当前 AI 讲完再发送」与「立即暂停全部再发送」两种方式；
  - **自动 / 手动轮流**：可让系统自动轮转，也可由用户点名下一个发言者；
  - 用户下达「**开工**」指令后，AI 从讨论转为**逐步落实产出**，并把结果**持续汇总更新到一份 Markdown「最终方案」文件**；
  - **多场讨论历史**可回看、可继续。
- **游戏模式（规划中）**：让 AI 自主游玩狼人杀，支持自定义道具及效果、自定义角色（狼人/平民等）的数量与功能。*（本阶段仅预留底层与界面占位，暂不实现对局逻辑。）*
- **原生体验**：完全使用 DSH 的主题 token、本地化与布局规范，**兼容深色/浅色主题与窗口缩放**，界面**中英双语**并跟随 DSH 语言设置自动切换。

## 🚀 使用方法

> ⚠️ 本项目采用**分阶段开发**，当前正在逐步实现中。以下为插件构建完成后的标准使用流程。

### 1. 获取项目

```bash
git clone https://github.com/shuran10086/Multi_AI_Conversation.git
```

插件源码位于 `插件本体/Multi_AI_Conversation/` 目录（一个可安装的 DSH bundle）。

### 2. 安装到 DeepSeek Harness

本插件是标准的 DSH bundle（含 `package.json` 与 `cordis.patch.yml`）。在 DSH 中通过插件管理能力，以 `插件本体/Multi_AI_Conversation/` 的**绝对路径**作为目标安装该 bundle 即可。安装成功后，左侧导航栏会出现「多AI对话」入口。

### 3. 配置 AI 模型

1. 点击左侧「多AI对话」打开插件页面；
2. 在配置区**添加 AI**（最多 6 个），为每个 AI 填写：昵称、API 地址（兼容 OpenAI 格式）、密钥、模型名，并可选填人设/温度/颜色；
3. 在「输出设置」里指定「最终方案」的**输出文件夹**。

### 4. 使用工作模式

1. 切换到「工作模式」，新建一场讨论；
2. 输入你的**项目目标**并发送；
3. 多个 AI 开始**轮流讨论**，你可以随时插话、调整规则（超时、轮流方式、插话方式等）；
4. 讨论成熟后点击「**开工**」，AI 转入逐步落实，并把方案持续写入你指定文件夹下的 Markdown 文件；
5. 任意一场讨论都会进入历史列表，可随时回看或继续。
